# soc.sucks One-Pager Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the soc.sucks single-page site per `docs/superpowers/specs/2026-07-30-soc-sucks-onepager-design.md`: a parody SIEM alert queue → diagnosis → manifesto → CraftedSignal reveal, plus a social og-image.

**Architecture:** One self-contained `index.html` (inline CSS + small vanilla JS, one Google Fonts link). Sections stack in one scroll: hero, queue, frame break, diagnosis, manifesto, reveal, footer. `og-image.png` is generated by screenshotting a standalone card HTML with headless Chrome.

**Tech Stack:** Plain HTML/CSS/JS. No build, no framework, no dependencies. GitHub Pages + existing CNAME.

## Global Constraints

- Single self-contained `index.html`; inline CSS and JS; exactly one external request category: Google Fonts (one `<link>`).
- No analytics scripts. Attribution only via CTA URL: `https://craftedsignal.io/?utm_source=soc.sucks&utm_medium=referral&utm_campaign=manifesto` (exact).
- Page fully readable and coherent with JavaScript disabled; JS is enhancement only.
- `prefers-reduced-motion: reduce` disables counter ticking, glitch/flicker animations, and smooth scrolling.
- WCAG AA contrast in both dark and white sections. Semantic HTML landmarks (`header`, `main`, `section`, `footer`), keyboard-reachable controls.
- `index.html` under 100 KB (excluding fonts, og-image).
- All copy comes verbatim from the spec's copy deck (microcopy polish allowed; tone and meaning fixed).
- og-image referenced by absolute URL `https://soc.sucks/og-image.png`.
- Design tokens (CSS custom properties on `:root`, exact starting values; may be tuned during implementation only if AA contrast requires):
  - `--bg: #0a0c10; --panel: #11151c; --line: #1e2530; --ink: #e8edf4; --ink-dim: #8b95a6;`
  - `--sev-critical: #ff5a5f; --sev-high: #ff9f43; --sev-medium: #ffd666; --sev-low: #4dabf7; --sev-info: #8b95a6; --sev-new: #c792ea;`
  - `--true-positive: #3ddc84;`
  - `--paper: #f4f1ea; --paper-ink: #14120e;`
- Fonts (single link, `display=swap`): JetBrains Mono 400/700 (SIEM chrome, metadata, rule names), Archivo Black (hero + frame-break display type), Instrument Serif 400/400-italic (diagnosis intro + manifesto articles).
- Class/ID contract used across tasks: `#alert-count` (hero counter number), `section.queue`, `article.alert-card[data-severity="critical|high|medium|low|info|new"]`, `button.dismiss[hidden]`, `section.diagnosis`, `section.manifesto`, `section.reveal`, `a.cta`.

### Task 6: JS enhancements

**Files:**
- Modify: `index.html` (one `<script>` before `</body>`)

**Interfaces:**

- [ ] **Step 1: Write the script.** Full behavior:

```html
<script>
(() => {
  const reduced = matchMedia('(prefers-reduced-motion: reduce)').matches;
  const counter = document.getElementById('alert-count');
  let count = 47832;
  const fmt = n => n.toLocaleString('en-US');
  const bump = (n = 1) => { count += n; counter.textContent = fmt(count); };
  if (counter && !reduced) {
    const tick = () => { bump(Math.random() < 0.2 ? 3 : 1); setTimeout(tick, 500 + Math.random() * 2500); };
    setTimeout(tick, 1200);
  }
  document.querySelectorAll('.queue .dismiss').forEach(btn => {
    btn.hidden = false;
    btn.addEventListener('click', () => {
      const card = btn.closest('.alert-card');
      const clone = card.cloneNode(true);
      const note = document.createElement('p');
      note.className = 'dup-note';
      note.textContent = '1 new alert';
      clone.prepend(note);
      clone.querySelector('.dismiss').addEventListener('click', e => { e.target.closest('.alert-card').remove(); bump(2); });
      card.after(clone);
      bump(2);
    });
  });
})();
</script>
```

Add `.dup-note` CSS (small `--sev-critical` mono tag).

- [ ] **Step 2: Verify enhancement.** Browser: counter ticks irregularly; clicking Dismiss spawns a duplicate flagged "1 new alert" and the counter jumps. With DevTools "Emulate prefers-reduced-motion: reduce": counter static. 

- [ ] **Step 3: Verify no-JS.** Browser with JS disabled (DevTools ⌘⇧P → "Disable JavaScript", reload): page fully readable, no Dismiss buttons visible, counter shows `47,832`.
